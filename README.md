# Margin

记录股票买卖、持仓盈亏和本人 / 对方分成的网页应用。纯静态页面，可直接部署在 GitHub Pages。

## 部署

1. 在 GitHub 新建一个仓库，例如 `margin`。
2. 把这几个文件上传到仓库根目录：
   - `index.html`
   - `manifest.webmanifest`
   - `icon-180.png`
   - `icon-512.png`
   - `README.md`
3. 打开仓库的 Settings → Pages，Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
4. 一两分钟后访问 `https://你的用户名.github.io/margin/`。

**不要把 `margin-backup-*.json` 上传到仓库。** GitHub Pages 的仓库是公开的，备份文件里是你的交易记录。

## 导入现有记录

1. 用手机 Safari 打开部署好的网址。
2. 点右上角齿轮 → 数据备份 → 从备份导入，选择 `margin-backup-20261015.json`。
3. 点「确认导入」。

## 添加到主屏幕

在 Safari 里点分享按钮 → 添加到主屏幕，就会以 Margin 图标出现在桌面上，打开后全屏显示，像原生应用一样。

## 说明

- **数据保存位置**：记录保存在当前浏览器的本地存储里，不会上传到任何服务器。换手机、换浏览器，或清除 Safari 网站数据之前，先在设置里「备份数据」。
- **行情**：持仓现价来自腾讯财经公开行情接口，交易时段（工作日 9:15–11:30、13:00–15:00）每秒刷新，其余时间每 30 秒刷新，可能有延迟。股票代码按名称自动匹配，可以在设置 → 行情代码里手动修正。
- **手续费**：买入默认按成交额的万分之一，卖出默认按万分之六（佣金万一加印花税万五），可以手动修改。
- **成本**：持仓成本按移动加权平均计算，包含手续费。
